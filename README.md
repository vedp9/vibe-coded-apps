# Vibe-Coded Apps

A collection of practical applications built through AI-assisted development workflows, also known as vibe coding.

This repository documents my journey of turning real-world ideas into working applications using AI for coding support, debugging, UI iteration, and faster prototyping.

> These projects were built with AI assistance. They are not necessarily AI-powered products unless they include an AI feature for end users.

## Projects

### Wool App

A Flutter mobile application built for my mother to create and manage a digital catalog of her handmade knitted items.

The app helps her:

- Upload photos of knitted products
- Add product names, descriptions, prices, and availability
- Organize handmade items in one place
- Browse previously added products
- Maintain a simple digital catalog for her work

**Tech stack:** Flutter, Dart, Supabase, SQLite, Provider, go_router, image_picker, and shared_preferences.

**Project:** [Open Wool App](./wool_project)

## AI-Assisted Development

AI tools supported the development workflow through:

- Turning product ideas into app screens and user flows
- Building and refining Flutter UI components
- Debugging implementation and package issues
- Exploring navigation, storage, database, and media integrations
- Improving code structure and speeding up iteration

The final implementation was reviewed, tested, and adapted based on the app’s real use case.
